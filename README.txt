# India 24 News Network — starter website

This is a free, static starter website for India 24 News Network / Khabar Fatafat.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace every demo/placeholder headline with verified reporting.
- Add your real logo, editorial email, phone number and social links.
- Add your editorial policy, corrections policy, privacy policy and terms.
- Do not publish unverified claims or use other channels' logos without permission.

## Free publishing option: GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, e.g. `india24-news-network`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. GitHub will show your public website address, usually `https://YOUR-USERNAME.github.io/india24-news-network/`.

GitHub Pages is suitable for this static starter site. It does not include a built-in news publishing dashboard; to add stories, edit `index.html` or move later to a CMS.
